# Corevanta AB Legacy Tag Updater

Corevanta AB Legacy Tag Updater is a Windows desktop application for modernizing Allen-Bradley PLC-5 projects converted to Studio 5000. It analyzes one or more L5X routine exports, replaces converted legacy file references with descriptive Logix tags, checks proposed mappings against exported controller tags, and generates import-ready L5X files.

## Download

Download the latest signed Windows installer from the [Releases](https://github.com/CorevantaLLC/corevanta-ab-legacy-tag-updater/releases/latest) page.

The application includes a 14-day free trial. No credit card is required. Analysis, mapping review, project files, and controller-tag safety checks remain available without an active license; Excel mapping import/export and updated L5X generation require a trial or commercial license.

## Supported legacy data files

- Input (`I`) and output (`O`)
- Binary (`B`)
- Timer (`T`) and counter (`C`)
- Integer (`N`) and floating point (`F`)
- Multiple routine L5X exports from the same controller
