## Corevanta Logix Modernizer 2.0.0

Corevanta Logix Modernizer replaces AB Legacy Tag Updater as the current product release while retaining compatibility with existing licenses and saved projects.

### New in version 2.0.0

- New Tag & I/O Remapping workspace for current Logix projects
- Selectable I/O, BOOL, integer, REAL, TIMER, COUNTER, STRING, and structured/UDT categories
- Direct module-defined I/O remapping across complete routines and Program exports
- Whole-object TIMER and COUNTER replacements, including instruction and status-bit references
- Program-level and multi-file L5X analysis
- Filter-aware Include All checkbox for fast mapping selection
- Excel mapping import and export
- Controller-tag conflict and data-type checking
- Project save and reopen using `.clmproject`
- Compatibility with legacy `.abltproject` files

### Preserved from Legacy Tag Updater

- Converted PLC-5 I, O, B, T, C, N, and F workflows
- Prefix-aware converted operands
- Existing descriptions and TIMER/COUNTER preset values
- Original L5X source files are never overwritten

The workflow is intentionally guided and requires no scripting: select, analyze, map, validate, and generate.
