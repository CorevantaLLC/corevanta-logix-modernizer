## Corevanta AB Legacy Tag Updater 1.0.0

Initial public installer release for the Corevanta AB Legacy Tag Updater Windows desktop application.

### Included workflows

- Scan one or more Studio 5000 L5X routine exports from the same controller
- Find converted PLC-5 input, output, binary, timer, counter, integer, and floating-point references
- Map converted operands to descriptive Logix tags in the application or Excel
- Import a Studio 5000 controller-tag CSV and flag existing tags, incompatible data types, and duplicate proposed names
- Preserve timer and counter member references while renaming the underlying tag
- Preserve available timer/counter initial values and tag descriptions
- Generate import-ready single-routine or ordered multi-routine L5X packages
- Save and reopen Legacy Tag Updater project files
- Use a 14-day free trial with no credit card required
